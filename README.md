# Conquistador Hub

1. plataforma responsive para dispositivos de windows, mac, android,ios, etc. 2. plataforma para control de actividades. donde debe haber un super administrador el pude agregar o eliminar cosas en el dashbord para todos. 3. Dashboard contiene: Sección de Tarjeta de Guía Mayor , Clases Progresivas Conquistadores,  Clases Avanzadas Conquistadores, Año Bíblico,Mi unidad, Ideales,  Conqui Kash. 4. El inicio de sesión debe ser mediante un número de telefono y una contraseña de 4 dígitos, al ingresar un nuevo usuario debe de colocar sus 2 nombres y 2 apellidos, número de celular, correo electrónico, Fecha de cumpleaños y colocar una opción de selección entre cargo de director, sub director, Integrante. (Si es director o subdirector que se registra agregar un panel de edición para el dashboard de los integrantes. 5. El año biblico debe verse por fecha la lectura biblica diaria y debe tener una barra de progreso de lecturas del mes y una barra de progreso de la sumatoria de los meses a un solo año. 6. dentro de la sección de unidades el super admin, director y sudirector pueden colocar a cada miembro un identificativo de Capitan o secretario. ademas en las unidades se evalua por integrante, asisitencia 5%, puntualidad 5%, uniforme 5%, tareas 5%, matutina 5%, cuota 5%, ese se evalua cada sábado de cada mes, por lo tanto cada integrante debe tener dos resultados, el primero de sumatoria del día y el segundo de las sumatoria de los 4 o 3 sábado de reunión. y al final debe haber una sumatoria de puntos de todos los integrantes para sacar el puntaje de la unidad total.
